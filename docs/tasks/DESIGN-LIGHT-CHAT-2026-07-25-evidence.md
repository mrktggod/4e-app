- empty;
- loading;

## Результат по раскладке

Автоматическая проверка не нашла горизонтального переполнения:

- `horizontalOverflow`: 0 записей из 48.
- элементы ниже viewport: 0 записей из 48.
- активные экраны в evidence: `ask`, `chats`, `chat-conv`.

На `390x844` в light-теме:

- `#ask` composer виден: `bottom=831` при высоте viewport `844`;
- `#chat-conv` composer виден: `bottom=834` при высоте viewport `844`;
- список чатов не имеет composer по контракту, там проверялись поиск и список.

## Контролы ввода

`AI-chat`:

- поле ввода есть;
- кнопка send есть;
- voice внутри composer не найден;
- attachment внутри composer не найден.

Это не CSS-баг. Сейчас voice живёт как отдельное действие навигации, а не как кнопка внутри `AI-chat` composer. Attachment для `AI-chat` тоже не реализован в текущей вёрстке.

`список чатов`:

- поиск есть;
- composer/send/voice/attachment не проверяются как обязательные, потому что это экран списка, а не экран переписки.

`chat-conv`:

- поле ввода есть;
- кнопка send есть;
- attachment-иконка есть;
- voice-иконка есть.

## Контраст

Для активных элементов критического падения контраста не найдено. Есть один пограничный design-debt:

- в light-теме вторичный текст списка чатов `.chat-row-prev` около `4.34:1`;
- в light-теме подзаголовок диалога `.conv-sub` около `4.34:1`.

Это ниже обычной цели `4.5:1` для мелкого текста. В этой задаче CSS не менялся, потому что это не точечная поломка одного экрана, а кандидат на аккуратную настройку light-токенов/secondary text.

## Empty/loading/error

Состояния empty/loading/error сняты как визуальные probes:

- `#ask`: через содержимое `#ask-msgs`;
- `#chats`: через содержимое `#chats-list-wrap`;
- `#chat-conv`: через содержимое `#conv-msgs-area`.

В текущей продуктовой логике список чатов при пустом ответе или ошибке часто уходит в `renderMockChatsList()`, поэтому реального постоянного error-state для `#chats` нет. Это не фиксировалось кодом, только записано как наблюдение.

## Вывод

Широкий редизайн не нужен. Узкого CSS-багфикса в рамках этой задачи не найдено.

Следующий безопасный кандидат: отдельный brief на light-тему secondary text, где можно поднять контраст `.chat-row-prev` и `.conv-sub` до `4.5:1+`, не меняя композицию экранов.
