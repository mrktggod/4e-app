# BRIEF-2026-07-30-110 — VK: не терять сессию при сетевом сбое (P0)

Разблокирует диагностику `BRIEF-2026-07-23-48-vk-auth-session-claude-scope` (status: NEED-CLAUDE → в работу). Ниже — ревью и одобренный план из `pm/outbox/REPORT-2026-07-23-48-vk-auth-session-claude-scope.md`, писать код можно.

### Контекст

`vk.html:1006-1018` (`bootstrapAuth()`): читает сохранённый токен `vk4_token`, делает `fetch(WORKER + '/auth/me', {headers:{'x-token':savedToken}})` с таймаутом 2500ms, парсит JSON без проверки HTTP-статуса, и **удаляет токен при ЛЮБОЙ ошибке** — таймаут, offline, DNS/CORS, 5xx, невалидный JSON, а не только при подтверждённом 401/403. Из-за этого пользователи ВК теряют вход при любом сетевом сбое — прямой удар по виральной петле (пришёл по ссылке → сессия оборвалась → не вернулся).

### Задача

1. `vk.html:1017-1018` — сохранять `vk4_token` при: таймауте, offline, DNS/CORS exception, 429, 5xx, невалидном/пустом ответе.
2. Удалять токен **только** при подтверждённом `401`/`403` или явном ответе воркера, однозначно означающем invalid token.
3. Явный logout (`vk.html:1329-1331`) продолжает удалять токен как раньше — не менять.
4. При временном сбое показывать восстанавливаемое состояние (не молча выкидывать в неавторизованный экран).
5. Добавить локальный/статический smoke вокруг `bootstrapAuth()` с мокнутыми исходами `/auth/me`: success, 401, 403, 500, timeout/rejection.

### Regression-чеклист (обязательно перед коммитом)

- Прямой web `vk.html`: токен переживает симулированный timeout/5xx/offline и восстанавливается после следующего успешного `/auth/me`.
- VK web iframe: signed launch params всё ещё триггерят VK-автологин, когда нет валидной сохранённой сессии.
- VK mobile WebView: bridge init/autологин не блокируется устаревшим direct-web состоянием.
- Явный logout всегда удаляет `vk4_token`.
- В логах/отчёте — только `<redacted>` для значений токена.

### Стоп-точки

- Не ослаблять и не менять backend auth-контракт (`/auth/me`, entitlement).
- Без прод-деплоя, без merge в `main`, без секретов в коммите.
- Без live VK-аккаунта/устройства — только синтетика/моки.

### Ожидаемый результат

Коммит с точным списком изменённых строк, новый smoke зелёный, `check-cp1251-mojibake` pass, REPORT с regression-чеклистом выше подтверждённым.
