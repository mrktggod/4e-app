# REPORT-VK-DIVERGENCE-PROFILE-HANDOFF

status: NEED-YURI

## Что найдено

В backlog есть задача `VK-DIVERGENCE-PROFILE-HANDOFF`: в основной версии есть marker `profile-handoff-shell`, а в `vk.html` его нет.

Это не безопасная ночная правка. В задаче прямо указано: не переносить автоматически, а сначала решить, нужен ли VK такой же профильный handoff.

## Что нужно решить Юрию

Нужно выбрать один вариант:

1. Переносим profile handoff shell в VK.
2. Оставляем отдельный VK-профиль и записываем причину.
3. Делаем отдельную согласованную задачу на общий профильный shell.

## Почему код не менялся

Профиль связан с личными данными, входом и настройками. Даже визуальный перенос shell без решения может изменить ожидания пользователя в VK.

## Где проверить после решения

После выбранного варианта можно запускать focused VK profile smoke и marker check для `profile-handoff-shell`.
