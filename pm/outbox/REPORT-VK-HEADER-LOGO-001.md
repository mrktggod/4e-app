## Что сделано

В VK Mini App убран второй логотип на первом экране. Теперь вверху остаётся один общий брендовый блок: значок `4` и подпись `AI-секретарь`. Центрированный дубликат под шапкой больше не выводится.

## Что нужно сделать Юрию

Ничего срочного. При следующей ручной проверке VK Mini App стоит просто открыть первый экран и убедиться, что логотип не повторяется два раза.

## Где проверить

Проверка добавлена в проект:

- `npm run smoke:vk-header-logo`

Также прошёл общий локальный VK-проверочный сценарий:

- `npm run test:e2e:vk`

Оплата, цены, доступ, production и live VK-действия не менялись.
