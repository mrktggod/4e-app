# REPORT-VK-TASK-COMPLETE-001

status: DONE

## Что сделано

В VK Mini App завершение задачи стало понятнее и безопаснее. Теперь приложение не считает любой ответ сервера успехом: если сервер вернул ошибку, пользователь видит понятное сообщение, а задача не исчезает из списка.

Если завершение прошло успешно, задача сразу убирается из активных локально, а потом список обновляется с сервера.

## Что нужно сделать Юрию

При следующей ручной проверке VK Mini App стоит нажать `Готово` у тестовой задачи и убедиться, что задача исчезает из активных, а после обновления страницы не возвращается.

## Где проверить

Локальная проверка добавлена в проект:

- `npm run smoke:vk-task-complete`

Также прошёл общий VK-сценарий:

- `npm run test:e2e:vk`

Оплата, цены, доступ, production и live VK-действия не менялись.
