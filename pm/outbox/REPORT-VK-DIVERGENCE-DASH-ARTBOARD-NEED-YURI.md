# REPORT-VK-DIVERGENCE-DASH-ARTBOARD

## Что найдено

В backlog есть задача `VK-DIVERGENCE-DASH-ARTBOARD`: в основной версии есть marker `dash-artboard`, а в `vk.html` его нет.

Это не безопасная ночная правка. В самой задаче прямо написано: не переносить автоматически, а сначала принять решение, что делать с VK-поверхностью.

## Что нужно решить Юрию

Нужно выбрать один вариант:

1. Переносим dashboard redesign shell в VK.
2. Оставляем VK в отдельном старом shell и записываем причину.
3. Заменяем обе поверхности на общий shell отдельной согласованной задачей.

## Почему код не менялся

Автоматический перенос dashboard shell в VK может поменять первый экран, навигацию и визуальную модель VK Mini App. Это продуктовый выбор, а не узкий багфикс.

## Где проверить после решения

После выбранного варианта ночной runner или отдельный brief сможет проверить marker counts для `dash-artboard` и локальный VK smoke.
